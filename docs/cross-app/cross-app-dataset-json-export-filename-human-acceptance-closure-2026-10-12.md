# Cross-App Dataset JSON Export Filename Human Acceptance Closure

Date: 2026-10-12

## Current disposition

**HUMAN BROWSER ACCEPTED / PASS / CLOSED (BOUNDED).** Human explicitly accepted the Dataset JSON Export filename consistency behavior across NarrativeLine, LiaisonScape, and ParameterPlotter on 2026-10-12. This closure applies only to the nine browser cases and behavior listed below. The Roadmap remains the current planning authority.

## Accepted behavior

- Prefer the Dataset title as a safe `.e2r.json` download filename.
- Keep the complete filename, including the extension, within 180 UTF-8 bytes.
- Preserve generated filenames within the byte limit without shortening them.
- Shorten only over-limit candidates using a Unicode-safe leading portion, an ellipsis, and a deterministic short hash.
- Use `e2r-dataset.e2r.json` when no usable title candidate exists.
- Keep the full, unshortened Dataset title in the exported JSON.

For the accepted long Japanese title case, all three apps generated the same hash, `d61fccfc`. When downloading a same-named file again, the browser may append a sequence such as `(1)` or `(2)`; this browser download behavior is separate from the filename generated by the application.

## Scope and limits

This closure accepts the title-derived filename behavior, the 180 UTF-8 byte limit, bounded shortening, deterministic cross-app output in the reviewed long-title case, and the title-less fallback for the nine cases above. It is not acceptance of every title, length boundary, Unicode sequence, browser, operating system, or filesystem. It does not establish broader Cross-App interoperability, Workspace safety, Dataset Replacement Safety, or public deployment behavior.

The separately tracked Roadmap follow-ups for Dataset title confirmation wording, Metadata declaration and Export self-description, and LiaisonScape diagnostic state remain open and do not block or alter this filename acceptance. Session 0105 retains its earlier pending-review checkpoint as historical evidence.

No application source, tests, or runtime behavior changed for this closure. PUBLIC RELEASE remains NO-GO; this Acceptance does not authorize commit, push, release, deployment, or publication.
