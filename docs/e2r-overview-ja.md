# E2R入門

E2Rは、できごと、エンティティ、そしてそれらの関連付けを、ひとつのデータセットとして交換するための仕様です。

## 3つの基本要素

- **できごと**：発生した出来事、活動、変化など。
- **エンティティ**：人物、組織、場所、物、概念など、存在するもの。
- **関連付け**：2つのできごとやエンティティをつなぐ関係。

E2Rの基本仕様は、これらの構造と識別子を定めます。関連付けが何を意味するか、また日付や表示方法をどう解釈するかは、拡張機能やアプリケーションが定めます。

## データセット

データセットは、基本仕様のバージョンと、できごと・エンティティ・関連付けの配列を持つJSON文書です。基本仕様では、これらの配列は空でも必須です。

```json
{
  "version": "1.0",
  "entities": [],
  "events": [],
  "relations": []
}
```

タイトルや日付など、基本仕様に含めない情報は拡張機能として追加できます。未知の拡張機能は、対応していないアプリケーションでも保持したまま読み飛ばせるよう設計されています。

## さらに詳しく

詳細なルールは、[E2R Core仕様](../spec/core.md)と各拡張機能の仕様を参照してください。
