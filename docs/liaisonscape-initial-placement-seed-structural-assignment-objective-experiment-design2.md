## Exact comparator contracts

### Normalized altitude

For a registered motif record, compare the accepted exact normalized chord
relief, conceptually:

~~~text
2 * abs(cross(B-A, C-A)) / L_max^2
~~~

Rational FP1 coordinates are compared by exact cross multiplication. No
square-root evaluation, epsilon, rounded float, scalar aggregation, or
cross-motif sum is allowed. Equal record values are preference-equivalent on
that record.

### FAN-P1

For each applicable shared Node with the same transported relevant neighbor
set and ray count, compare the exact smallest positive circular directed gap
g_min. A larger g_min means only greater local narrowest-bottleneck relief.
It does not express angular uniformity or a graph-wide score.

Use the accepted exact directed-gap comparator with exact integer/rational ray
components, sign-aware normalized-dot comparison, and no atan2, square root,
epsilon, or degree rounding. Unsupported representation or unresolved required
input returns UNKNOWN.

### PP-M3

PP-M3 compares each applicable registered record separately. X dominates Y
only when every required comparable record is equal or favors X and at least
one record favors X. If one defined axis favors X and another favors Y, the
fixture-level result is PP-INCOMPARABLE. Missing required coverage or exactness
is PP-UNKNOWN. Shared non-applicability is PP-NOT-APPLICABLE.

PP-PREF-EQUIVALENT and PP-PROFILE-EQUIVALENT remain distinct. No scalar score,
weighted sum, total rank, or winner is constructed.
