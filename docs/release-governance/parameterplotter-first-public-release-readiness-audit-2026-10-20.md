## M1 verification, blockers, and M2 handoff

New in this audit: live public `main` refs were read without fetching or writing; local/public Git blobs and workflows were inspected; ParameterPlotter `npm.cmd run check` passed **238/238** tests and Hub `npm.cmd test` passed **7/7**, with Hub `npm.cmd run lint` passing. Earlier accepted-checkpoint evidence (not rerun here) includes ParameterPlotter DOM **13/13** and production build. Local source, test and browser evidence do not establish a public Deployment PASS. The bounded HTTP 404 is a current absence of service at the expected URL, not a Runtime failure in a deployed build. No tracked file outside this M1 document was changed during the audit.

**No newly confirmed defect in the accepted current Product source was found.** Public Release remains **NO-GO** because the precise RC/public-write set, publication configuration and public-environment verification are outstanding. The outdated public Ashen/Lighthouse content and absent public ParameterPlotter/Hub route are concrete sequencing constraints; pushing a Hub route against those revisions without a deliberate plan could give users the wrong Dataset version. The missing authenticated Pages/settings access is an operational verification gap. These are conditions for M2 planning and later public writes, not grounds to undo local Product acceptance.

M2 can start with a Human choice of (1) exact ParameterPlotter RC identity/SHA, (2) exact Spec/Hub/LiaisonScape push set and order or a separately authorized narrower alternative, (3) production Ashen URL variables and Lighthouse route policy, and (4) bounded Hub visual review and pre-public test gates. Recheck live remote SHAs and audit every approved full range at that time. Public Write, tag, workflow dispatch, deployment, rollback and final Release approval remain **separate Human decisions**. After an authorized deployment, verify the exact served assets and Dataset revisions, then perform bounded HTTPS/Handoff, guide, save/Export and failure checks. If deployment fails or a serious safety issue is found, record actual public state and ask Human before any revert, rollback or alternate SHA publication.
